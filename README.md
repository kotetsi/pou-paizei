# Πού Παίζει

Site που δείχνει σε ποια πλατφόρμα streaming παίζει κάθε ταινία και σειρά στην Ελλάδα.

- `index.html` — το site
- `admin.html` — διαχείριση ελληνικών πλατφορμών (ERTFLIX, ANT1+ κ.ά.)
- `greek-platforms.json` — οι ελληνικές πλατφόρμες και οι τίτλοι τους
- `worker.js` — ο proxy για το TMDB API, τρέχει στο Cloudflare Workers (δεν χρησιμοποιείται από το GitHub Pages)
- `discover.js` — η καρτέλα «Τι να δούμε;»: είδος ταινίας, εύρος ετών, πραγματική βαθμολογία IMDb ή TMDB και πλατφόρμες στην Ελλάδα

## Ανακάλυψη ταινιών

Στην καρτέλα «Τι να δούμε;», διάλεξε είδος, προαιρετικά έτος από/έως, πηγή βαθμολογίας και όριο. Για ακριβώς το 2000, βάλε 2000 και στα δύο πεδία. Το «πάνω από 7,5» είναι αυστηρό: ταινία με 7,5 δεν περνάει.

Η προεπιλογή δείχνει μόνο τίτλους με γνωστή διαθέσιμη πλατφόρμα στην Ελλάδα. Μπορείς να διαλέξεις όλες τις επιλογές (και αγορά/ενοικίαση), συνδρομή/δωρεάν ή μόνο δωρεάν. Συμπεριλαμβάνονται οι καταχωρισμένοι τίτλοι του `greek-platforms.json`. Τα στοιχεία διαθεσιμότητας μπορεί να αλλάξουν· οι ελληνικές καταχωρίσεις χρειάζονται συντήρηση από τη διαχείριση.

Τα αποτελέσματα ελέγχονται ανά σελίδα, κατά δημοτικότητα. Ο μετρητής αφορά μόνο όσες ταινίες έχουν ήδη ελεγχθεί. Το «Έλεγχος περισσότερων ταινιών» συνεχίζει την αναζήτηση· μια άδεια σελίδα δεν σημαίνει ότι δεν υπάρχουν άλλες ταινίες. Δεν προστίθενται demo αποτελέσματα όταν αποτυγχάνει η αναζήτηση.

## Ενεργοποίηση IMDb

Οι βαθμολογίες IMDb λαμβάνονται από το [OMDb](https://www.omdbapi.com/), μέσω του Worker. Δεν χρησιμοποιείται η βαθμολογία TMDB ως υποκατάστατο IMDb και δεν εφαρμόζεται προφίλτρο βαθμολογίας TMDB όταν επιλέγεται IMDb.

1. Απόκτησε κλειδί από [OMDb API key](https://www.omdbapi.com/apikey.aspx) και ενεργοποίησέ το από το μήνυμα email τους. Έλεγξε τα τρέχοντα όρια και τους όρους του παρόχου πριν επιλέξεις πλάνο.
2. Στο Cloudflare, άνοιξε **Workers & Pages → pou-paizei-api → Settings → Variables and Secrets → Add**.
3. Πρόσθεσε **Secret** με όνομα `OMDB_API_KEY` και τιμή το κλειδί. Διατήρησε το υπάρχον `TMDB_TOKEN`.
4. Στο **Edit code**, αντικατάστησε τον Worker με το ενημερωμένο `worker.js` και κάνε **Deploy**. Η ενημέρωση στο GitHub Pages δεν ενημερώνει αυτόματα τον Cloudflare Worker.
5. Ανέβασε/συγχώνευσε και τα `index.html` και `discover.js` στο branch που δημοσιεύει το GitHub Pages.
6. Δοκίμασε «Τι να δούμε;» → IMDb → «Βρες ταινίες». Χωρίς το κλειδί ή χωρίς τον νέο Worker εμφανίζεται σαφές μήνυμα και παραμένει διαθέσιμη η ρητή επιλογή TMDB.

Μην προσθέσεις το κλειδί σε HTML, JavaScript του browser ή στο GitHub. Το endpoint `?path=imdb/movie/<TMDB id>` επιστρέφει μόνο IMDb ID, πηγή και βαθμολογία. Οι βαθμολογίες IMDb αποθηκεύονται για 7 ημέρες, στη μνήμη του Worker και στο cache του Cloudflare, γιατί το δωρεάν κλειδί OMDb έχει όριο 1.000 κλήσεις την ημέρα. Κάθε σελίδα αποτελεσμάτων με IMDb μπορεί να χρειαστεί έως 20 κλήσεις. Το cache του Cloudflare λειτουργεί πλήρως μόνο σε custom domain. Άγνωστες βαθμολογίες δεν περνούν το φίλτρο. Σφάλματα ορίου κλήσεων ή κλειδιού εμφανίζονται ως σφάλματα και δεν αποθηκεύονται ως «χωρίς βαθμολογία».
